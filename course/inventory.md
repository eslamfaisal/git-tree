## How to read the tables

- **UI** quotes `apps/desktop/src/app/i18n/en.ts` exactly (labels, menu items, dialog titles, button names). Arabic equivalents sit under the same keys in `apps/desktop/src/app/i18n/ar.ts` (parity enforced by `apps/desktop/src/app/i18n/parity.test.ts`); this file lists English only. Right-click menus use the longer forms from `command.menu.*` (for example "Merge {{label}} into {{current}}"); the palette and the contract use the short command titles. Both are quoted where they differ.
- **Command / shortcut** is the command id from `tooling/contract-snapshots/ui-commands-contract.json` (276 commands) and its default chord from that file's `keymap` (27 chords). `Mod` = Cmd on macOS, Ctrl on Windows and Linux. "none" means the command has no default chord. `Mod+Tab` / `Mod+Shift+Tab` are not delivered on macOS (the OS switcher owns them); `Ctrl+Tab` / `Ctrl+Shift+Tab` are the cross-platform pair (`apps/desktop/src/app/commands/keys.ts`).
- **Status** is the ledger status plus task id. P00-T01..T24 are `done` (P00-T25..T31, the owner actions, are `blocked`); P15-T16 and P15-T17 are `done` (their UI was later removed, see Not shipped).
- **Source** path abbreviations: `defs/` = `apps/desktop/src/app/commands/definitions/`; `feat/` = `apps/desktop/src/features/`; `ws/` = `apps/desktop/src/app/workspace/`; `git/` = `crates/ogt-infrastructure/src/git_cli/adapters/`; `uc/` = `crates/ogt-application/src/use_cases/`. `file:N` is the line of the first definition.
- **Plain git** is what the adapter actually runs (read from the adapters), not what the brief says.
- Where there is no command id the cell says "no command id".

Total rows and the VERIFY list are at the end of the file.

## Not shipped / excluded

- **Merges are not undoable from Undo.** A plain "Merge Into Current Branch" is not journaled (only `UndoOp::Rebase` is recorded at `uc/integrate.rs:274`); cherry-pick, revert and a pull in merge mode are not journaled either. The only merge entry in the Undo journal is the one the Gitflow "Finish…" writes (`uc/gitflow.rs:515`). Use Reset or the reflog to go back (see V7).
- **Bitbucket issues are off** (capability `issues: false`; Atlassian removed the native tracker and its API on 2026-08-20). Bitbucket Data Center issues are also off (Jira, out of scope). Azure DevOps has no issues (Boards out of scope).
- **Gitea**: no provider code exists; the brief lists it under "Later", and `README.md:121` lists it as not in wave 1 (see V10: the wording differs from "non-goal").
- **No AI features except commit-message drafting** through the user's own coding-agent CLI (ADR-0017, status "proposed"): no key or account held by GitTree; the staged diff goes to the agent only when the user clicks. No cloud patches, teams, launchpad, agents tab, licensing, telemetry.
- **Account management is not in the app**: profile, organisations, invitations and account deletion live on the website; the app has a read-only Account summary and Sign out (P15-T22). Organization onboarding UI (P15-T16, T17) is `done` in the ledger but was removed.
- **Linux**: `.deb` and `.AppImage` only, x86_64 only; **unsigned** (verify with `SHA256SUMS.txt`); no arm64, no `.rpm`, no Flatpak, no Snap (ADR-0018). Ubuntu 22.04 needs `ppa:git-core/ppa` for Git 2.39+.
- **macOS and Windows installers are unsigned** until the owner enrols (P00-T26, P00-T27 / P12-T04, P12-T05 blocked): Gatekeeper and SmartScreen warn on first launch. No Mac App Store, no MSI.
- **Updater key pair is blocked** (P00-T28): the in-app updater (ADR-0021, no Tauri updater plugin) verifies SHA-256 only; it catches a corrupt or swapped download, not a compromised release. A minisign `.sig` becomes mandatory once `UPDATER_PUBLIC_KEY` exists.
- **GitLab and Azure DevOps browser sign-in** are not configured in the official build (`OGT_GITLAB_CLIENT_ID` and `OGT_AZURE_CLIENT_ID` are empty): those use tokens (or a typed OAuth application ID for GitLab).
- **No libgit2 or gitoxide**: every action is the `git` CLI (that is why every row has a "plain git" column).
- Pageant, MSI installer and bundled Git: deferred past 1.0 (`DESIGN_BRIEF.md` §1.4). Multi-window and detached tabs: deferred.
- **Not in the ledger as done**: v0.1.0 contract freeze (P05-T17 in-progress), clean-VM smoke matrix (P12-T14 todo), publish v1.0.0 (P12-T15 todo), perf benches (P02-T16 in-progress), centre-view conflict slot + E2E (P06-T14 in-progress).
