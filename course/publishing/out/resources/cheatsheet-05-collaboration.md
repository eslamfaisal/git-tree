# Commands: Collaboration: remotes, pull requests, providers

| Command | Lesson |
|---|---|
| `git push -u origin <branch>` | Git push in GitTree: send your commits to a remote |
| `git config --get-regexp push` | Check where a Git push will go before you push |
| `git pull --ff-only --no-rebase` | Git pull --ff-only in GitTree |
| `git pull --ff-only` | Git pull: fast-forward if possible, else merge |
| `git merge <upstream>` | Git pull: fast-forward if possible, else merge |
| `git rebase --autostash <upstream>` | Git pull --rebase in GitTree |
| `git config pull.ff only` | Choose your default Git pull mode in GitTree |
| `git config pull.rebase true` | Choose your default Git pull mode in GitTree |
| `git fetch` | Git push rejected (non-fast-forward): how to fix it |
| `git pull --rebase` | Git push rejected (non-fast-forward): how to fix it |
| `git push` | Git push rejected (non-fast-forward): how to fix it |
| `git push --force-with-lease=<ref>:<expected-sha>` | Git force push with lease: the safe way in GitTree |
| `git push origin --delete <branch>` | Delete a remote Git branch from GitTree |
| `git push origin refs/tags/<tag>` | Push a Git tag to the remote in GitTree |
| `git fetch --all` | Git auto-fetch: keep remote branches up to date |
| `git clone <https-url>` | Clone a repository from your hosting account in GitTree |
| `git remote add origin <url>` | Publish a local Git repository to a host from GitTree |
| `git fetch <remote> <pr-head>:refs/ogt/pull/<n>` | Check out a pull request branch locally in GitTree |
| `git branch <name>` | See issues and start a branch from one in GitTree |
