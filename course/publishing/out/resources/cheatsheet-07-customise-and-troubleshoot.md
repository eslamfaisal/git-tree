# Commands: Customise GitTree and fix problems

| Command | Lesson |
|---|---|
| `git config user.name` | Git profiles in GitTree: work and personal identities |
| `git config user.email` | Git profiles in GitTree: work and personal identities |
| `ssh-keygen -t ed25519` | SSH keys in GitTree: generate, copy and test |
| `ssh -T git@<host>` | SSH keys in GitTree: generate, copy and test |
| `git config gpg.format ssh` | Sign Git commits in GitTree (OpenPGP, SSH, S/MIME) |
| `git config commit.gpgsign true` | Sign Git commits in GitTree (OpenPGP, SSH, S/MIME) |
| `git difftool` | Set an external diff tool, merge tool and editor |
| `git mergetool` | Set an external diff tool, merge tool and editor |
| `git credential fill` | Where GitTree stores your tokens (system keychain) |
| `git config --global` | Export, import and reset GitTree settings |
