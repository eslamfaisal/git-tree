# Commands: Start here: install, sign in, open a repository

| Command | Lesson |
|---|---|
| `git --version` | Install GitTree on macOS (Apple silicon and Intel) |
| `xcode-select --install` | Install GitTree on macOS (Apple silicon and Intel) |
| `sudo apt install ./Git-Tree-Linux.deb` | Install GitTree on Ubuntu and Debian (.deb) |
| `chmod +x Git-Tree-Linux.AppImage` | Run GitTree on Linux with the AppImage (no root) |
| `./Git-Tree-Linux.AppImage` | Run GitTree on Linux with the AppImage (no root) |
| `sha256sum -c SHA256SUMS.txt` | Verify a GitTree Linux download with SHA256SUMS |
| `git rev-parse --git-dir --is-inside-work-tree` | Open a Git repository in GitTree (folder or drag and drop) |
| `git config --list --show-scope --show-origin` | Trust this repository? What GitTree checks before it opens |
| `git clone <url> <dest>` | Clone a Git repository by URL in GitTree |
| `git init --initial-branch main` | Create a new Git repository in GitTree (git init) |
