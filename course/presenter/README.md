# Presenter

`profile.jpg` is the lecturer's photo. It is used **only** where an author is credited: the small circular bubble with
the name plate inside each video, and the channel avatar. It is never used in thumbnails, hero images or large sections.
`presenter.yml` holds the name and title. The bubble's ring pulses with the voice.

`voice/` holds the voice sample the narrator is cloned from. It is gitignored and never committed (see `../audio/README.md`).
