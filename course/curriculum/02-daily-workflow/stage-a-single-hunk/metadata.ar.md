# 02-02 · الوصف بالعربية

**العنوان**: `كيف تُجهِّز Hunk واحدًا في GitTree وتحفظ جزءًا من الملف`

**الوصف**

```
احفظ تعديلًا واحدًا فقط من تعديلين في الملف نفسه. في هذا الدرس تتعلّم ما هو الـ hunk، وكيف تعمل منطقة التجهيز (staging area)، وكيف تُجهِّز hunk واحدًا في GitTree، مع الأمر المقابل git add -p.

الفصول
0:00 لماذا نحفظ جزءًا من الملف؟
0:24 ما هو الـ hunk؟
0:55 الأماكن الثلاثة التي يحفظ فيها Git عملك
1:30 افتح التعديلات واختر الملف
1:50 اضغط Stage Hunk
2:10 ملف واحد في قائمتين
2:30 راجع واكتب الرسالة وأنشئ الـ commit
3:10 الشيء نفسه في Git: git add -p
3:50 نصيحتان وخلاصة

لتجرّب بنفسك بالمستودع نفسه:
course/demo-repo/build.sh ~/lumen two-hunks
https://github.com/eslamfaisal/git-tree/tree/main/course

حمّل GitTree مجانًا لأنظمة macOS وWindows وLinux:
https://gittree.app/ar/download?utm_source=youtube&utm_medium=video&utm_campaign=02-02

الأوامر المقابلة
git add -p src/search/index.ts
git diff --staged

الدرس القادم: تجهيز أسطر محددة.
GitTree غير تابع لأي برنامج Git آخر.
```

**الوسوم**: جت تري, شرح git, git add -p, تجهيز جزء من الملف, staging area, hunk, تقسيم الـ commit, واجهة git رسومية, دورة git بالعربي, git للمبتدئين

**الوسوم الرمزية**: #GitTree #Git #شرح_git

**التعليق المثبّت**: `جرّب بنفسك: course/demo-repo/build.sh ~/lumen two-hunks ثم افتح المجلد في GitTree. أيّ commit قسّمته أولًا؟`

**وصف الصورة المصغّرة**: صورة المحاضر على الجهة اليمنى (للاتجاه من اليمين لليسار)، وفي اليسار الفروقات بلونين وزر Stage Hunk؛ والنص: «Hunk واحد».

*أوقات الفصول مؤقتة إلى أن يُسجَّل الصوت النهائي.*
